Issue: bob --chat-mode rejected in the pipeline's bob container (Lab 1)

Reported by user39 Branch / commit user39-labs / 7e1a677 Jenkins job user39/user39-pipeline, build #3 Result UNSTABLE (expected SUCCESS)

Summary

The PR Review stage fails because the bob CLI inside the pipeline's bob container (image-registry.openshift-image-registry.svc:5000/jenkins/bob-cli:latest) does not recognise the --chat-mode option. The same option is accepted by a current Bob Shell installed locally (version 1.0.4). The pipeline code appears to be correct; the bob-cli:latest image is the likely cause.

What Happened

The askBob helper runs:

bob --chat-mode pipeline-git-diff-overview -p "Read git-diff.txt and produce the senior-developer PR overview." --hide-intermediary-output

Console output from build #3:

+ bob --chat-mode pipeline-git-diff-overview -p Read git-diff.txt and produce the senior-developer PR overview. --hide-intermediary-output
error: Invalid argument — unknown option '--chat-mode'
Run `bob --help` for usage.
Fatal error: error: unknown option '--chat-mode'
ERROR: script returned exit code 1
Setting overall build result to UNSTABLE
The PR Review stage wraps the Bob call in catchError(buildResult: 'UNSTABLE', stageResult: 'FAILURE'), so the Bob failure marks the build UNSTABLE rather than failing it outright. Because Bob never ran, bob-pr-review.md was not created and nothing was archived.

Evidence

Local Bob Shell — bob --version → 1.0.4. bob --help lists:

--chat-mode   the mode to use for interaction, must be one of: 'plan', 'code',
              'advanced', 'ask', 'CCP', 'code-reviewer', 'documentation-writer',
              'mode-writer', 'code-analyzer', 'zdocs', 'trust-control-auditor',
              'rules-writer', 'wxo-agent-architect', 'jenkins-bob-integration',
              'pipeline-git-diff-overview'
  • --chat-mode is a valid option locally, and pipeline-git-diff-overview is an accepted value.
  • -p/--prompt is marked deprecated in 1.0.4 ("Use the positional prompt instead"). It still works today but will be removed in a future version.
  • The Bob Shell docs also still document --chat-mode.

Likely Cause

The bob binary in bob-cli:latest is a different (probably older) build than the Bob Shell 1.0.4 used locally. Not yet confirmed — the version inside the image has not been checked.

How to Confirm

Run one of the following and compare with 1.0.4:

oc run bob-help --rm -it \
  --image=image-registry.openshift-image-registry.svc:5000/jenkins/bob-cli:latest \
  -- bob --version

Or add a temporary step to the pipeline:

container('bob') { sh 'bob --version; bob --help' }

Requested Action for the Instructor

  1. Check the Bob Shell version in bob-cli:latest and rebuild or refresh the image with a current Bob Shell if it is out of date.
  2. Confirm whether other participants see the same unknown option '--chat-mode' error in Lab 1.
